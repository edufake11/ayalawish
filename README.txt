MI WISHLIST — SITIO WEB

1. Abre index.html para verla en tu computadora.
2. Para compartirla online, sube index.html y la carpeta assets a un repositorio de GitHub.
3. Settings > Pages > Deploy from a branch > main / root > Save.
4. El enlace será https://TU-USUARIO.github.io/NOMBRE-REPO/
